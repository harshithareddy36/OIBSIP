# BMI Calculator (Python, Beginner Tier)

A command-line program that calculates Body Mass Index (BMI) and shows the health category.

## Features
- Asks for weight (kg) and height (m)
- BMI = weight / (height x height), shown to 2 decimals
- Categories: Underweight, Normal, Overweight, Obese
- Rejects letters, zero and negative numbers

## How to run
```

py bmi_calculator.py
```


## Example
```
Enter weight in kg: 60
Enter height in meters (e.g. 1.65): 1.58
Your BMI is 24.03
Category: Normal
```
